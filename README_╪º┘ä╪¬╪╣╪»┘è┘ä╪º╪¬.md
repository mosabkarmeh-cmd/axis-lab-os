# ملخص التعديلات

## الملفات المعدّلة (استبدل هاي بنسختك الأصلية بنفس المسارات)
- `server.ts`
- `src/App.tsx`
- `src/db/schema.ts`
- `src/db/sync.ts`
- `src/server/routes/production.ts`

## خطوة إجبارية بعد النسخ
الـ schema تغيّر (جداول/أعمدة جديدة: `app_state`, `supplier_quotes`, أعمدة جديدة بـ `materials` و`machines`).
لازم تشغّل هاد الأمر بعد استبدال الملفات وقبل ما تشغّل السيرفر:

```
npx drizzle-kit push --config=src/db/drizzle.config.ts
```

تأكد إنو `.env` عندك فيه `SQL_HOST` / `SQL_USER` / `SQL_PASSWORD` / `SQL_DB_NAME` صحيحين ومتوصلين بقاعدة بيانات Postgres شغالة قبل هالأمر.

## أهم الإصلاحات
1. باج `.env` ما كان يتحمّل (ترتيب استيراد خاطئ بـ server.ts) → كل شي متعلق بقاعدة البيانات كان معطل.
2. نظام حفظ تلقائي (`app_state`) للطلبات/المستخدمين/المحاسبة/الفواتير/الإعدادات... تنجى من إعادة التشغيل.
3. توحيد سعر الصرف بمصدر واحد (`SETTINGS.exchangeRate`) بدل 3 أرقام متضاربة.
4. ربط العملاء، المنتجات، المواد، المخزون، الموردين، طلبات التوريد، مقارنة أسعار الموردين، والماكينات كلهم بجداول Postgres حقيقية موحّدة (كانت متقطعة عن بعضها - "split-brain").
5. جدول جديد: `supplier_quotes` (مقارنة أسعار الموردين).
