# AXIS LAB OS documentation

This directory contains the canonical documentation for the current codebase.

- `deployment.md` — current production deployment procedure.
- `releases/` — historical release notes only; these are documentation records, not alternate source versions.
- `audits/` — audit evidence and review records.

The source of truth for application behavior is the current source tree and automated tests. Do not add copied source files, timestamped variants, ad-hoc test reports, or machine-specific data snapshots to the repository.
